# Тема: классификация проектов объектов капитального строительства

Идея для дипломной работы родилась по месту работы. Мы занимаемся разработкой инженерного ПО, а именно CAD системой для проектирования зданий и сооружений.

**Описание:** есть база данных росреестра (csv файл >250000 записей) проектов прошедших госэкспертизу за несколько последних лет. Нужно разделить проекты на категории интересные нам:

- Автомобильные дороги
- Водоотведение
- Водопроводы
- Газоны дорожки
- Газопроводы
- Горные выработки
- Железнодорожные пути
- Заводы фабрики
- Здания
- Инженерное обеспечение
- Инфраструктура наземного электротранспорта
- Линии электропередачи
- Метрополитены
- Мосты и тоннели
- Наружное освещение
- Нефтепроводы
- Сооружения
- Теплопроводы
- Технологические установки

Это часть внутреннего анализа рынка, который нам нужен для корректировки развития продукта.

**Данные**: выгрузка из росреестра, аналитик по продукту разметил 100 записей каждой из 19 категорий (1900 размеченных записей).

**Источник данных**: https://egrz.ru/organisation/reestr/latest

**Проблемы**: 
- имена проектов это небольшие предложения, классические методы основанные на tf-idf метриках не работают, лемматизация удаляет связи между словами
- нет следования какому-то одному паттерну именования. Можно встретить как названия из нескольких слов, понятных только в каком-то узком контексте, так и длинные сложносочененные названия
- используется масса аббревиатур, многие из которых  не являются стандартными аббревиатурами проектной или рабочей документации, нет единого словаря этих аббревиатур
- нет никакой корреляции между категориями и ОКВЭД организации, прошедшей экспертизу

**Идея:**
- предобработка текста (удаление лишнего, расшифровка аббревиатур)
- дообучение нескольких разных предобученных моделей нейронных сетей на подготовленных размеченных данных
- классификация текста с помощью обученных моделей, сравнение результатов

Классические методы обработки текста построенные на лемматизации, tf-idf метриках не рассматриваю, так как тексты очень маленькие, приведение к нормальной форме удаляет нужный контекст.
